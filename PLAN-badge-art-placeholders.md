# PLAN — Badge art placeholders to replace · v1

Status: **reminder for the founder (2026-10-25).** These badges are live with code-drawn placeholder art (drawn by
`scripts/badge_art/designs.py`). The founder will replace them with art that matches the original bedazzled set.

## How to replace one
Save the new art (PNG or WebP, square, 1600 px or larger) with **exactly the same file name and folder** as the
placeholder below and upload it to the repo (or send it to me). Nothing else changes: the badge picks it up by path.
Big originals (4K) can also go in `art/badges-4k/` with the same path.
