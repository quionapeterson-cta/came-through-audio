# Drop files here for Claude

Photos, MP3s, badge art, icons, documents: drag them into this folder in the Codespace file list (left side), then
tell Claude what they're for. Claude moves each one where it belongs (badge art to public/icons/…, homepage photos to
public/home/…) and resizes or converts it if needed.

Files you drop here stay in the Codespace only; they are never uploaded to GitHub or the website until Claude places
them (so private MP3s don't end up in the project's history).
